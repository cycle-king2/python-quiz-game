# Python Console Quiz Game

모듈화 구조와 입력 검증, 상태 저장/복구(`state.json`) 기능을 적용한 콘솔 기반 퀴즈 게임입니다.

---

## 1. 프로젝트 개요 및 퀴즈 주제 선정 이유

- **주제 선정 이유:** 김다미 배우를 좋아해 팬들이 좋아할 주제로 4지선다 퀴즈 출제·등록·점수 관리와 JSON 파일 저장/복구 흐름을 직접 구현하고 검증하기 위해 선정했습니다.

- **주요 기능:**
  - 퀴즈 풀기 : 저장된 퀴즈를 순차 출제하고 '정답/오답' 여부에 따라 최종 결과를 출력
  - 퀴즈 문제 출제 및 정답/오답 판정, 점수 집계
  - 퀴즈 목록 : 저장된 전체 퀴즈 목록을 확인하며, 등록된 퀴즈가 없는 경우도 처리
  - 새 퀴즈 등록 및 기본 퀴즈(`default_quizzes.py`) 연동
  - 현재 최고 점수를 조회하고, 풀이 결과에 따라 최고 점수를 비교·갱신하여 저장합니다.
  - 사용자 입력 검증(`input_utils.py`) 및 진행/기록 상태 저장·복구(`state.json`)

---

## 2. 프로젝트 구조 및 모듈 역할

**코드파일 구조:**
- `main.py`: 프로그램 진입점 및 메뉴 실행 흐름 제어
- `quiz.py`: 개별 퀴즈 데이터 및 문제/정답 처리 로직
- `quiz_game.py`: 게임 루프, 점수 관리, 상태 저장 및 불러오기 로직
- `default_quizzes.py`: 기본 제공 퀴즈 데이터 목록
- `input_utils.py`: 콘솔 사용자 입력 검증 유틸리티

**데이터 파일(`state.json`) 설명:**
  - **저장 경로:** 프로젝트 루트(`~/projects/python-quiz-game/state.json`)
  - **역할:** 퀴즈 데이터와 최고 점수를 저장·불러오기하며, 파일이 없거나 손상/오류 발생 시 예외 처리를 거쳐 기본 퀴즈 데이터로 안전하게 동작

  - **필드 구조:**
    ```json
    {
      "quizzes": [
        {
          "question": "문제 내용",
          "options": ["선택지1", "선택지2", "선택지3", "선택지4"],
          "answer": 1
        }
      ],
      "best_score": 0
    }
    ```
