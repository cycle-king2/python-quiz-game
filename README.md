# python-quiz-game# Python Console Quiz Game

모듈화 구조와 입력 검증, 상태 저장/복구(`state.json`) 기능을 적용한 콘솔 기반 퀴즈 게임입니다.

김다미 배우에 대한 간략한 퀴즈로 구성해 보았습니다.

## 주요 기능
- **퀴즈 풀기:** 등록된 4지선다 퀴즈를 풀고 점수를 누적합니다.
- **새 퀴즈 추가:** 질문, 보기 4개, 정답 번호(1~4)를 입력받아 퀴즈를 추가합니다.
- **퀴즈 목록 보기:** 현재 등록된 퀴즈와 정답 번호를 확인합니다.
- **현재 점수 보기:** 누적 점수와 등록된 퀴즈 수를 확인합니다.
- **상태 저장 및 복구:** 진행 상황과 퀴즈 목록을 `state.json`에 저장하며, 파일이 없거나 손상된 경우 기본 퀴즈(`default_quizzes.py`)로 복구합니다.

## 프로젝트 구조
- `main.py`: 콘솔 메뉴 출력 및 프로그램 실행 진입점
- `quiz_game.py`: `QuizGame` 클래스 및 `state.json` 저장·불러오기·복구 로직
- `quiz.py`: `Quiz` 클래스(문제, 보기, 정답, 화면 출력 및 채점)
- `default_quizzes.py`: 초기 기본 퀴즈 5개 제공
- `input_utils.py`: 범위 내 정수 입력, 빈 문자열 방지, 예외 처리 유틸리티
